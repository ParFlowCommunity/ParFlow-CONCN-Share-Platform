# 测试与验证

本文规定验证方法和结果记录要求，不表示任意部署环境已通过验收。运行日志、截图、数据库副本和具体服务器测试报告应保存在私有工作目录，不作为公共使用说明。

## 自动化测试

Python 测试覆盖认证、权限、申请、下载任务、边界、包内容、源数据校验和科学网格；前端测试覆盖下载轮询、地图读数、高亮、SDK 加载及请求标识。

在项目根目录执行：

```bash
conda activate concnshare
mkdir -p .local/test-tmp
TMPDIR="$PWD/.local/test-tmp" timeout 60s python -B -m unittest discover -s tests -v
node --test frontend/tests/*.test.js
```

后端测试会重建专用 concn_datahub_test 中的测试记录，需预先配置可丢弃测试库及相应权限。不得将正式业务记录放入测试库。测试读取 backend/.env 连接信息并覆盖数据库名。合成数据测试不替代真实科学验证。

## 部署验收

| 范围 | 验证内容 |
| --- | --- |
| 服务 | 网站及 MySQL 健康检查，独立 worker 正常运行 |
| 账号 | 注册、登录、退出、普通用户与管理员权限隔离 |
| 目录 | 七级流域、精确编号搜索、省市定位和地图选择 |
| 地图 | 默认地形、切换标准、首次加载、SDK 失败重试、瓦片请求 |
| 授权 | 小流域名额、额外申请、审核、撤销和越权拒绝 |
| 任务 | 排队、裁切、取消、失败原因、过期清理 |
| 文件 | 真实 ZIP 文件数、内容、元信息、大小和 CRC；Range 下载和归属限制 |
| 科学 | 栅格对齐、坐标方向、源窗口逐像元比较、掩膜与计算域有效性 |
| 网络 | 目标用户网络直连、HTTPS、反向代理和邮件链接 |
| 运维 | 重启恢复、备份恢复、文件一致性和容量 |

浏览器测试应使用新会话检查首次访问，并记录失败请求的状态。SDK 加载成功不代表瓦片全部成功；服务器本机可达也不能代替远端用户验证。

## 结果记录

每次实际验证记录源码版本、环境、执行命令、测试范围、结果和已知限制。未执行的项目标记为未验证，不引用其他部署的测试数量作为本次结论。证据包含凭据或业务资料时应限制访问，并在共享前脱敏。
