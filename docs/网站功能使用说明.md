# ParFlow CONCN Share Platform 网站功能使用说明

## 1. 进入网站

在运行服务的电脑打开 http://127.0.0.1:8000/data/view 。其他电脑须使用服务器可达的 IP 和端口，不能使用 127.0.0.1 访问你的电脑。校园网即使连接相同 Wi-Fi，也可能限制设备之间访问。

顶部包含网站首页、流域数据、使用说明、公告。流域数据可以下拉，目前只有一个流域数据入口。右上角可切换中文/英文；登录后点击自己的名字打开个人菜单。

## 2. 注册与登录

1. 进入登录页并切换注册。
2. 填写用户名（4–64 字符）、唯一邮箱及密码（8–128 字符，含字母和数字），确认密码。
3. 注册成功后回到登录表单，输入邮箱和密码登录。用户名用于显示，不是当前登录凭据。
4. 连续多次输错密码会暂时锁定账号；不要不断重复提交。

忘记密码、邮箱验证和修改邮箱依赖平台邮件服务。没有配置时相关功能不能完成。退出登录位于用户名菜单。

## 3. 流域地图

### 3.1 查找和定位

- 选择省份，再选择城市，地图定位到相应区域。行政区定位不会改变裁切边界。
- 流域编号必须填写完整 14 位数字，保留开头的零；不支持名称和部分编号搜索。
- 选择第 1–7 级流域并搜索，或直接点击地图上的流域边界。
- 搜索结果显示橙色，点击选择显示绿色。搜索后点击旁边流域，橙色搜索结果仍保留；右侧显示当前选中流域的信息。
- 切换级别保留地图视野。重置用于清除筛选/选择，页面之间切换则保留现有地图状态。

### 3.2 地图工具

左上方可以切换地图类型。左下角显示随缩放更新的比例尺，右下角显示鼠标实时经纬度；鼠标移出地图后坐标留空。地图全屏按钮已移除。右侧流域信息栏可收起，显示编号、级别、经纬度范围和面积。

离开地图到个人页面再返回，通常保留搜索、流域选择和地图视野；强制刷新或重新打开浏览器后不保证恢复。

## 4. 下载数据

### 4.1 有直接下载资格

1. 登录后选择流域，点击顶部“下载数据”。
2. 在“填写下载用途”窗口确认流域编号。
3. 填写科研单位（最多 100 字）、下载用途（最多 200 字），例如科研分析、毕业设计、课程教学或项目开发。
4. 可展开“查看条款”，阅读并勾选同意后点击“下载”。
5. 任务进入排队和处理状态。关闭弹窗不会取消任务。
6. 准备完成后点击“保存 ZIP”，也可以到“我的下载”保存。

当前下载完整包，不能选单个变量。用途资料随任务保存在平台中，不附带在公开压缩包里。

### 4.2 需要审核

默认第 5–7 级属于小流域，每账号免审核累计两个不同编码；同一编码可重复下载。大流域或超过名额的新小流域需要申请。管理员调整阈值后，以网站当前规则为准。

弹出申请表时，填写姓名、单位、用途、申请原因及可选项目链接。邮箱使用当前账号邮箱；用途和申请原因各至少 10 字。勾选条款后提交，每次只申请一个流域。

在“我的申请”查看状态和审核意见。待审核申请可以撤回；通过后在授权有效期内下载；驳回可调整说明重新申请。授权被撤销或过期后不能继续使用原授权。没有累计只准提交两次申请的限制。

从已通过申请直接获取或从历史任务重新操作，目前不一定再次显示上述用途弹窗。

## 5. 用户名下拉菜单

| 页面 | 可做的事情 |
|---|---|
| 我的下载 | 查看任务时间、流域级别、编号、文件大小、状态；保存已准备包；取消活动任务；重新获取失败/过期任务 |
| 用户中心 | 查看账号和免费名额；修改用户名、密码；邮件服务可用时修改/验证邮箱 |
| 我的申请 | 查看提交记录、审核意见和有效期，提交申请、撤回待审记录、使用已通过授权 |
| 通知 | 查看审核通过/驳回/撤销及数据包准备完成事件，全部标记已读 |

“我的下载”有活动任务时会局部更新状态，不会反复刷新整个网页；也可以手动刷新。显示成功并不保证文件永久存在，默认归档保留 72 小时。过期后需重新生成，并重新检查资格。

修改密码后需要重新登录。账号停用后已有会话也失效。

## 6. 压缩包内容

下载文件名为 `ParFlow_CONCN_Share_Platform_流域编号_下载日期.zip`，日期格式 YYYYMMDD，按下载时北京时间计算。

解压后只有一个流域编号文件夹，其中有 slopex、slopey、bedrock、manning、subsurface 五个 PFB 输入，mask 的 TIF/PFB 两个文件，PF SOL 计算域文件、VTK 文件及 metadata.json，共 10 个文件。

不包含 README.txt、CITATION.txt 或哈希值文本。metadata.json 中 pfbas_level 表示第 1–7 级，版本为 concn1.1。旧包可能仍使用旧格式，重新提交任务生成的包才应用新规范。

详细文件名见[下载包内容与文字维护](下载包内容与文字维护.md)。这些数据不是直接开箱运行的完整模拟项目，使用者仍需准备自己的模拟配置。

## 7. 管理员功能

管理员登录后，从用户名菜单进入相应管理入口，管理工作台可以切换以下页面。

| 页面 | 操作说明 |
|---|---|
| 申请审核 | 筛选待审核或其他状态，查看姓名/单位/用途/原因；填写审核意见后通过、驳回或撤销授权 |
| 共享规则 | 设置小流域起始级别、结果保留小时数、授权有效小时数和维护模式；填写变更原因并确认发布 |
| 账号管理 | 一个搜索框同时搜索用户名或邮箱；支持部分匹配、搜索/重置和分页；停用或启用普通账号 |
| 处理任务 | 查看任务状态、失败原因和处理情况，取消活动任务 |
| 数据版本 | 查看数据版本与共享状态；“停止共享”会使该版本不可继续下载，不是修改版本显示名称 |
| 双语内容 | 新建或编辑文章，分别填写中英文标题/正文；存为草稿或发布 |
| 操作审计 | 查看管理动作、操作者、对象及时间 |

工作台的可用存储指任务文件所在磁盘的剩余空间，不是个人可用额度。当前任务列表还不能展示或导出下载用途。

网页账号管理不能直接新增管理员，也不能把普通账号提升为管理员。新增管理员由服务器维护人员使用后端 `python -m datahub.cli admin` 交互命令完成，运行环境必须指向正确数据库。

## 8. 修改使用说明和公告

进入管理工作台 → 双语内容 → 选择类型“帮助”或“公告” → 填写中英文标题和正文 → 选择“已发布” → 保存。编辑已有内容时点“编辑”，修改后保存；改为草稿则不在公开列表展示。

无已发布帮助内容时显示：“这里将展示网站的使用指南和常见问题解答”。无已发布公告时显示：“这里将展示平台的最新公告和动态信息。” 本说明文件不会自动上传成为网页文章，需通过后台维护网站内容。

## 9. 常见问题

- **找不到流域：** 检查是否 14 位数字、前导零和当前级别是否正确。
- **省份选好却没有城市：** 检查行政区目录是否导入、请求是否成功；不是流域裁切故障。
- **地图空白或很慢：** 检查底图网络、天地图密钥及代理，高级别边界较大时需等待加载。
- **为什么第三个小流域要申请：** 免费额度累计不同编码，不按下载点击次数计数。
- **下载没有立即开始：** 首先生成压缩包，准备完成后才保存文件；可以在我的下载查看。
- **文件已失效：** 文件保留期或授权已到期，重新获取或重新申请。
- **别人打不开网站：** 需要检查服务器监听、系统防火墙及校园网设备互访规则；本机能打开不代表其他电脑可达。
- **看不到最新界面：** 保存当前输入后按 Ctrl + F5 强制刷新。
