# 源码发布说明

## 发布内容

发布项目源码、数据库迁移及默认数据脚本、配置模板、依赖清单、测试、文档和必要图片。保留上游来源和作者声明；科学数据的许可与传输由数据提供方另行确认。

公开仓库不包含真实 .env、密码、业务 SQL 备份、数据库物理文件、科学源数据、下载 ZIP、node_modules、构建缓存或私有测试记录。.local 用于本机工作资料，不随源码发布。

## 提交前检查

检查 git status、暂存差异及未跟踪文件，确认实际部署所需代码均已纳入版本，同时不提交密钥和业务数据。.gitignore 不等于完整的敏感信息检查，尤其不要将业务导出 SQL 放进 database/migrations。若仓库历史曾包含私有内容，应在公开前单独审查历史。

具体机器的完整路径清单、迁移结果和运行状态应保存在私有目录。公开文档使用配置变量与示例地址，不复制生产运行日志。

## 获取源码后的部署

仅克隆仓库不会恢复账号、科学数据或有效下载结果。全新站点按 [部署说明](部署说明-v1.0.md) 初始化；继承现有站点按 [数据库继承与部署交接](数据库继承与部署交接.md) 恢复业务库和文件。两种流程不可混用。

保留 package-lock.json，通过 npm ci 恢复前端依赖；Python 环境依据 environment.yaml 和 requirements 安装。配置由部署方创建，不将真实值写回示例文件。
