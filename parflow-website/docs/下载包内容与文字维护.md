# 下载包内容与文字维护

## 目录与文件

ZIP 内仅有一个以 14 位流域编号 B 命名的文件夹，内含 11 个文件：

| 文件 | 内容 |
|---|---|
| slopex.B.pfb、slopey.B.pfb | 两个方向的坡度输入 |
| bedrock.B.pfb | 裁切后的 bedrock 源数据 |
| manning.B.pfb | 曼宁糙率输入 |
| subsurface.B.pfb | 裁切后的地下介质源数据 |
| mask.B.tif、mask.B.pfb | GeoTIFF 和 PFB 流域掩膜 |
| B.pfsol、B.vtk | ParFlow 计算域与可视化文件 |
| metadata.json | 流域、对外版本、生成时间、网格和文件名信息 |
| CITATION.txt | 引用要求与正式引用条目，正文由平台按数据版本生成 |

下载包不再包含 README.txt 和 SHA256SUMS.txt。

CITATION.txt 由 package_content.citation_text 生成，引用条目取自数据版本的 citation 字段，不写死在代码里。流水线若自带同名文件会被替换，避免发出过期引用文字。修改引用条目请在数据版本中维护，然后重启网站及空闲 worker。

## 修改其他文字
- 对外版本：编辑 [package_content.py](../backend/datahub/package_content.py) 中 PUBLIC_VERSION，然后重启网站及空闲 worker，使常驻进程加载新的包修订标识；已在执行的任务不应强行中断。裁切子进程在新任务执行时读取当前代码。该值不修改数据库的内部数据版本。
- metadata 字段规则：同一 Python 文件的 public_metadata 函数。新增、删除字段需同步维护本文及测试。
- 网页“使用说明”：在管理员后台“双语内容”中编辑帮助文章并发布；下载包不附带使用说明文本。

## 小流域审核与存储

每个账号可免审核取得两个不同的小流域，同编码可重复下载。额外小流域可以提交申请，通过审核后从申请记录下载，不新增免费槽位。大流域仍需申请；每份申请一个流域，可以多次提交，授权受账号、编码、数据版本及有效期约束。小流域即使尚有免费名额也允许提交申请。

生成任务保存于 backend/jobs/任务ID/attempt-次数/，其中 result.zip 是下载包，outputs/流域编号/ 是打包前文件。浏览器下载名称为 ParFlow_CONCN_Share_Platform_流域编号_下载日期.zip（北京时间 YYYYMMDD，例如 ParFlow_CONCN_Share_Platform_01010101010100_20260914.zip）。
