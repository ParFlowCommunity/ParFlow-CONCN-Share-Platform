# 项目结构与文件说明

## 整体链路

```text
浏览器 → 配置的网站入口 → backend/app.py (Waitress / Flask)
                              ├─ frontend/dist：构建后的 Vue 网页
                              ├─ datahub/api → services → repositories → MySQL
                              └─ 下载请求写入 MySQL 队列
独立 datahub/workers/queue.py → workers/clip.py → concnshare/run_two.py
                              → 共享目录中的 PFB、边界、模板
                              → Linux pfmask-to-pfsol → backend/jobs 中的 ZIP
```

`clip.py` 负责网站任务与科学工具之间的衔接；真正的掩膜、裁切流程在 `concnshare`。MySQL 存目录和业务记录，海量原始科学数据存磁盘，不存入 MySQL。

## 顶层目录

| 路径 | 职责 |
| --- | --- |
| `backend/` | 网站 API、身份权限、数据库访问、异步任务和本地运行数据 |
| `frontend/` | Vue 页面、地图、样式、构建配置和浏览器端测试 |
| `concnshare/` | 科学掩膜、PFB 裁切和域转换编排 |
| `database/` | SQL 表结构、迁移和默认数据，不是运行数据库目录 |
| `scripts/` | Linux 运行入口和省市导入工具 |
| `deploy/` | 当前部署文档入口 |
| `docs/` | 需求、功能、API、数据库、部署、维护和测试资料 |
| `tests/` | Python 后端与科学工具自动化测试 |
| `Fig/` | 科学说明图片 |
| `.local/` | 本机凭据、迁移备份、测试证据和整理原件，Git 忽略 |
| `.git/` | Git 提交记录、分支和对象元数据；不是业务文件 |

## 本地配置与运行目录

| 路径或配置 | 用途 |
| --- | --- |
| backend/.env | 后端本地配置，包含数据库连接和科学路径，不提交 |
| frontend/.env.local | 地图密钥与前端构建变量，不提交 |
| frontend/node_modules | npm 安装依赖 |
| frontend/dist | 网页构建产物，部署时生成 |
| backend/boundary_cache | 可重建的边界缓存 |
| CONCN_JOB_ROOT | 任务工作目录和结果 ZIP，默认 backend/jobs |
| .local | 私有运行日志、凭据、备份和验证证据 |
| MySQL datadir | 数据库物理文件，由 MySQL 服务配置决定 |
| CONCN_INPUT_PFB_DIR / CONCN_SHP_DIR / CONCN_TIF_DIR | 外部科学输入目录 |

业务文件、备份与缓存的保留要求不同，不应一起删除。数据继承流程见 [数据库继承与部署交接](数据库继承与部署交接.md)。
